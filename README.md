## ✨ Featured Work & Open Source

### [AdsMind](https://github.com/NagatoBigSeven/AdsMind) 🚀

<p align="center">
  <a href="https://github.com/NagatoBigSeven/AdsMind">
    <img src="https://media.githubusercontent.com/media/NagatoBigSeven/AdsMind/main/assets/concept.png" width="100%" alt="AdsMind: adsorption proposals, force-field relaxation, and self-correcting physical feedback" />
  </a>
</p>

<details open>
<summary><b>🎞️ Animated research loop · workflow schematic · click to toggle</b></summary>

<p align="center"><img src="./assets/adsmind-workflow.gif" width="100%" alt="AdsMind workflow schematic: propose, relax, verify, and self-correct; not an experimental recording" /></p>

A conceptual loop illustration; it does not depict a recorded run or measured timing.

</details>

Finding stable adsorption configurations on heterogeneous catalyst surfaces has long been a laborious trial-and-error process. **AdsMind** automates this with a multi-agent closed loop: LLM agents propose candidate structures, a machine-learning force field relaxes them, and a physics-grounded verifier self-corrects errors — no human in the loop.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)

  <a href="https://github.com/NagatoBigSeven/AdsMind" title="Code"><img src="./assets/badges/project-code-en.svg" height="38" alt="Code" /></a>
  <a href="https://github.com/NagatoBigSeven/AdsMind/blob/main/docs/quickstart.md" title="Quick start"><img src="./assets/badges/project-quickstart-en.svg" height="38" alt="Quick start" /></a>
</p>

<a href="https://github.com/NagatoBigSeven/AdsMind/tree/main/datasets/samples" title="AdsMind sample structures"><img src="./assets/badges/examples-en.svg" height="20" alt="AdsMind sample structures" /></a>
<a href="https://github.com/NagatoBigSeven/AdsMind/stargazers"><img src="https://img.shields.io/github/stars/NagatoBigSeven/AdsMind?style=flat-square&amp;label=Stars&amp;color=A4ABD6" height="20" alt="AdsMind GitHub stars" /></a>

<p align="center">
  <a href="https://arxiv.org/abs/2606.19152v1"><img src="./assets/adsmind-results-en.svg" width="100%" alt="AdsMind: AA20 100%; OCD-GMAE62 98.8%; approximately 14x fewer MLFF relaxations than heuristic enumeration" /></a>
</p>

[Reported preprint results and benchmark scope](https://arxiv.org/abs/2606.19152v1).

**My contribution:** Led the closed-loop architecture development, built the benchmark framework, and conducted cross-backend evaluation. [Code history](https://github.com/NagatoBigSeven/AdsMind/commits/main/?author=NagatoBigSeven).

**Try it:** Start with the supplied catalyst slabs and an adsorbate SMILES; inspect the [run report, structure files, and rendered configuration (when available)](https://github.com/NagatoBigSeven/AdsMind/blob/main/docs/quickstart.md#outputs).

### [CatDT](https://github.com/AI4QC/catdt-gs) 🧪

<p align="center">
  <a href="https://github.com/AI4QC/catdt-gs#digital-twin-workflow" title="CatDT architecture and workflow">
    <img src="./assets/catdt-architecture.svg" width="100%" alt="CatDT hub-and-spoke multi-agent digital-twin architecture" />
  </a>
</p>

A self-evolving multi-agent digital twin for autonomous heterogeneous catalyst discovery, coordinating surface reconstruction, reaction-pathway analysis, and microkinetics from a bulk crystal and a natural-language reaction description.

<p>
  <a href="https://arxiv.org/abs/2606.05050" title="Paper"><img src="./assets/badges/project-paper-en.svg" height="38" alt="Paper" /></a>
  <a href="https://github.com/AI4QC/catdt-gs" title="Code"><img src="./assets/badges/project-code-en.svg" height="38" alt="Code" /></a>
  <a href="https://github.com/AI4QC/catdt-gs#quick-start" title="Quick start"><img src="./assets/badges/project-quickstart-en.svg" height="38" alt="Quick start" /></a>
</p>

<a href="https://github.com/AI4QC/catdt-gs/stargazers"><img src="https://img.shields.io/github/stars/AI4QC/catdt-gs?style=flat-square&amp;label=Stars&amp;color=A4ABD6" height="20" alt="catdt-gs GitHub stars" /></a>

<p align="center">
  <a href="https://arxiv.org/abs/2606.05050v2"><img src="./assets/catdt-results-en.svg" width="100%" alt="CatDT: memory-augmented reinforcement loop improves barrier-calculation success from 41% to 84% across 600 catalytic surfaces" /></a>
</p>

[Reported preprint results and benchmark scope](https://arxiv.org/abs/2606.05050v2).

**My contribution:** Co-author and research contributor to CatDT — [paper authorship](https://arxiv.org/abs/2606.05050) · [system implementation](https://github.com/AI4QC/catdt-gs#agent-tool-architecture-how-it-actually-works).
